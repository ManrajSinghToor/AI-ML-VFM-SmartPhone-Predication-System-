# Smart Value For Money Mobile Finder

## Project Objective

This project recommends smartphones based on user requirements.

Users provide:

- Budget
- RAM
- Storage
- Front Camera
- Back Camera

The system predicts a Value Score and recommends the top 5 smartphones.

---

## Machine Learning Algorithms Used

1. Linear Regression
2. Random Forest Regressor
3. Gradient Boosting Regressor

The best performing model is selected and saved as:

best_model.pkl

---

## Features

- Data Cleaning
- Feature Engineering
- Model Comparison
- Graph Generation
- Smartphone Recommendation System
